# Engram Memory Harness

## Propósito

Mantener decisiones y contexto durable entre sesiones, independientemente del
agente utilizado.

## Reglas

1. Leer `Engram.md` al iniciar una sesión.
2. Actualizarlo cuando se tome una decisión técnica durable.
3. Mantener estado operativo transitorio en `harnesses/state.md`.

## Incluye

- Stack y comandos.
- Decisiones técnicas y su razón.
- Convenciones y restricciones del proyecto.
- Referencias a ADRs.

## No incluye

- Código o specs completas.
- Secretos, credenciales o datos personales.
- Recibos RDD fabricados o copiados como sustituto de autoridad.
- Resultados de pruebas que no fueron ejecutadas.
