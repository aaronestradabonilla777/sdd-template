# Documentación

Este directorio contiene decisiones arquitectónicas y guías durables.

## ADRs

1. Copia `ADR_template.md`.
2. Nómbralo `ADR-NNN-nombre-corto.md`.
3. Documenta contexto, opciones, decisión y consecuencias.
4. Añade una referencia breve en `Engram.md`.

Los ADRs explican por qué existe una decisión. La spec define comportamiento y
el recibo RDD, cuando existe, autoriza un candidato exacto; ninguno sustituye a
los otros.
